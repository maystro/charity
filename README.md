# جمعية عهد الخير للتنمية والخدمات

نظام إدارة داخلي لجمعية التضامن الاجتماعي في بني سويف. يتابع الحالات والأسر، البحث الاجتماعي، طلبات المساعدة، الزيارات الميدانية، المتبرعين والتبرعات، ثم تنفيذ المساعدات وإعادة التقييم.

الواجهة بالعربية، والصلاحيات مفصولة حسب الدور: مدير، مندوب ميداني، مستخدم، وحساب تقني للسوبر أدمن.

## ما يغطيه النظام

- **الحالات والأسر**: إنشاء الحالة، الأعضاء، الدخل، السكن، الأعباء، والمراجعة حتى الاعتماد أو طلب الاستكمال.
- **البحث الاجتماعي والزيارات**: جدولة الزيارات، تنفيذها، ومتابعة المتأخر منها.
- **طلبات المساعدة**: تقديم الطلب، بنوده، المرفقات، واعتماده ثم متابعة موعد التنفيذ.
- **إعادة التقييم**: تنبيه بالحالات المعتمدة التي حان موعد إعادة تقييمها.
- **المتبرعون والتبرعات والمشاريع**: سجل المتبرعين، التبرعات، ومراحل المشاريع.
- **المندوبون**: كل مندوب يرى الحالات والطلبات المرتبطة به فقط.
- **أدوات السوبر أدمن**: النسخ الاحتياطي، النشر، الصيانة، والنشر الذكي للملفات المتغيرة.

## التشغيل محلياً

يلزم PHP 8.4 و Composer و Node.js.

```bash
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate --seed
npm install
npm run build
php artisan serve
```

ثم افتح `http://127.0.0.1:8000`.

أثناء التطوير يمكن تشغيل السيرفر والطابور والسجلات و Vite معاً:

```bash
composer run dev
```

إذا كان المشروع يعمل عبر Laravel Herd فالموقع متاح على `https://charity.test` ولا حاجة لتشغيل `php artisan serve`.

## حسابات التجربة

بعد `migrate --seed` تكون كلمة المرور لكل الحسابات `password`:

| المستخدم | الدور |
| --- | --- |
| `admin` | مدير النظام |
| `agent` | مندوب ميداني |
| `superadmin` | السوبر أدمن التقني |

غيّر هذه الكلمات قبل أي استخدام حقيقي.

## ملاحظات الإنتاج

الإنتاج يعمل على استضافة مشتركة (Hostinger / LiteSpeed). على هذا السيرفر `exec()` و `symlink()` غير متاحين، وروابط `/storage/` تُحجب قبل وصولها إلى Laravel. الملفات العامة تُخدم عبر المسار `/media/{path}` وليس عبر رابط التخزين التقليدي.
